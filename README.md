# جمّول (Jamool)

منصة عربية للأطفال: قصص، حروف وأرقام، قصار السور، ألعاب، رسم، قيم ومسابقات.
React + TypeScript + Vite + Tailwind + GSAP (RTL).

```bash
npm install
npm run dev        # http://127.0.0.1:5200
npm run build:fast # يُخرج الموقع في مجلد out
```

- روابط السوشيال في الفوتر: `src/data/social.ts` (الآن تفتح صفحة «تواصل معنا» حتى تُضاف الروابط الحقيقية).
- النشر على Vercel: `vercel.json` يضبط الإخراج وإعادة توجيه المسارات إلى `index.html`.
